# Bangla-HSC-RAG-System-using-Gemma-2b
A Production-Ready Retrieval-Augmented Generation (RAG) system for Bangla HSC books. Parses PDFs, extracts MCQs, creative questions, tables, and paragraphs. Uses hybrid FAISS+BM25 retrieval with priority boosting, resolves MCQ answers accurately, and generates context-aware responses using Mistral-7B-Instruct.
